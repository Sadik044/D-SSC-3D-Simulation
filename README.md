# SSC 3D Atom Simulation

A Bengali-first, responsive educational atomic model for Bangladesh SSC students (classes 9–10).

## Features
- Browse the first 30 elements from hydrogen to zinc.
- Search elements by Bengali/English name, symbol, or atomic number.
- Animated canvas-based Bohr-style atom with pause, view toggle, rotate, and zoom controls.
- Particle counts, shell distribution, electron configuration, and selected ion examples.
- Build-an-atom activity and 10-question SSC quiz.
- Responsive layout for desktop and mobile.

## Run
This is a static website. Open `index.html` or deploy the repository as a static site on Vercel. No build command or backend is required.

## Science note
The canvas scene is an educational, simplified Bohr-style illustration, not a quantum-mechanical 3D electron-density model. Check element data and electron configurations against the current textbook before exam publication.
